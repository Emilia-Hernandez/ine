# Handoff técnico validado

Para comenzar, lea `GUIA_PARA_POLITOLOGOS.md` y abra `SECCIONES_ELECTORALES_CLASIFICADAS.csv` junto con `DICCIONARIO_VARIABLES.csv`.

La predicción operativa es persistencia histórica. La predicción centrada, los scores y los perfiles son insumos exploratorios con etiquetas explícitas de alcance y procedencia.

La metodología completa está en `METODOLOGIA_TECNICA_FINAL.md`; las pruebas y restricciones de uso están en `VALIDACION_FINAL.md`.
