# Paquete de auditoría

Empiece por `AUDIT_EXECUTIVE_SUMMARY.md`. Los cinco temas solicitados están en `AUDIT_FIVE_ISSUES.md`; el resto separa linaje, validación, consistencia documental, reproducibilidad, revisión adversarial y plan de corrección.

`AUDIT_ISSUES.csv` es el registro priorizado. `results/` contiene resultados reproducibles; `figures/` visualizaciones SVG; `AUDIT_TESTS/` scripts y pruebas. Ningún archivo original del proyecto fue modificado.
